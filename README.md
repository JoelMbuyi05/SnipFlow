# SnipFlow
Snipflow a web application that helps developers save, organize, and access code snippets instantly. It's like a personal code library in the cloud. 
It’s designed for developers who learn by building and want a clean, reliable way to manage their personal code library.

# 🛠 Technologies Used

# Frontend
* HTML5
* CSS3
* Tailwind CSS
* JavaScript (ES6+)

# Backend & Services
* Firebase Authentication (Google OAuth)
* Cloud Firestore (database)

# Tools & Deployment
* Git & GitHub
* Vercel
* VS Code

# ⭐ Features

* Google authentication with Firebase
* Create, edit, delete code snippets
* Search snippets by title, language, tags, or code
* Pin and favorite important snippets
* One-click copy to clipboard
* Dark mode support
* Offline support using localStorage fallback

# 🧪 Development Process

The project started with defining the core problem: developers constantly lose useful code snippets or store them in scattered places. I began by designing a clean layout focused on fast access and readability.

After building the HTML structure, I styled the application using Tailwind CSS to achieve a modern and responsive interface. Once the UI was stable, I implemented Firebase Authentication to allow users to securely sign in using Google.

Next, I integrated Firestore to store snippets in the cloud and retrieve them in real time. JavaScript logic was then added for creating, editing, deleting, pinning, and searching snippets.

Finally, I added quality-of-life features such as dark mode, clipboard copy, offline support, and UI feedback. The app was tested, cleaned up, and deployed.
